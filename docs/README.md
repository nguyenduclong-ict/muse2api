# Tài liệu hệ thống `muse2apiv2`

Thư mục `docs/` được tổ chức theo cấu trúc 5 tầng:

```text
docs/
├── 00_common/          # Từ điển thuật ngữ, quy chuẩn chung, tech stack
├── 01_srs/             # Đặc tả yêu cầu tổng quan (What & Why)
├── 02_basic_design/    # Thiết kế kiến trúc, API, Database, Screens (High-Level How)
├── 03_features/        # Đặc tả chi tiết từng tính năng (spec, design, logic)
└── 04_tasks/           # Quản lý kế hoạch và tiến độ triển khai
```
